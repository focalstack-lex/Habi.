# UI Simplification & Cognitive Clutter Audit Report

**Project**: Habi (Davao Local Fashion Discovery Platform)  
**Date**: 2026-09-27 00:38:00  
**Audit Scope**: Full Codebase Audit across all 8 Core Views, Section Header Banners, Feature Grids, and Modal Overlays.  
**Execution Command**: `/simplify-ui`  

---

## Executive Summary & Scorecard

| Lens / Metric | Current Baseline | Audited Goal | Identified Priority Fixes |
|---|---|---|---|
| **Copy Density & Wordiness** | 20-28 words per subtitle | 6-12 words per subtitle | P0: Section Header Headers (55% reduction target) |
| **Headline Scannability** | Full explanatory sentences | Punchy value statements | P1: Banner Subtitles & Footer Brand Copy |
| **Container Padding / Vertical Density** | `p-8 sm:p-12` heavy dark blocks | `p-6 sm:p-8` balanced whitespace | P1: Dark Hero & Section Header Banners |
| **Action Button Streamlining** | Dual competing CTAs in Heros | Single dominant CTA + text link | P2: Hero Action Stack & Seller Cards |
| **Metadata Scannability** | Multiline status text | Compact micro-metadata chips | P2: Seller Cards & Drop Cards |

### Pillar 4: Vertical Density & Whitespace Tuning

- **File & Location**: Section Banner containers in [`App.tsx:L165`](file:///c:/Users/User/Pictures/Habi/src/App.tsx#L165), [`DropsView.tsx:L15`](file:///c:/Users/User/Pictures/Habi/src/views/DropsView.tsx#L15), [`DavaoFashionMap.tsx:L179`](file:///c:/Users/User/Pictures/Habi/src/components/map/DavaoFashionMap.tsx#L179), [`FitCheckView.tsx:L19`](file:///c:/Users/User/Pictures/Habi/src/views/FitCheckView.tsx#L19).
- **Current Issue**: Padding set to `p-8 sm:p-12`. On smaller screens or standard laptops, this creates massive, dominating dark blocks that push grid content down.
- **Simplification Proposal**: Reduce container padding to `p-6 sm:p-8 md:p-10`, creating a balanced, scannable vertical rhythm.
